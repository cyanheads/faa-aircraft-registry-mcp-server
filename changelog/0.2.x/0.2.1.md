# 0.2.1 — 2026-11-15

On first open after upgrading, an index built by 0.2.0 withholds every non-type-certificated builder name until `mirror:refresh` completes, and three new indexes build. Model and exact-code searches still find those records.

## Added

- **Mode S decode** — when a `modeSCode` search matches nothing, the notice names the N-number the address encodes and `encodedNNumber` carries it; an address that encodes no N-number gets its own sentence. ([#34](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/34))
- **Designator spellings** — `makeModel` and `query` match hyphenated and joined designators interchangeably (`PA28` and `PA-28`), with the term as typed always kept. A search adds at most 20 spelling variants, in term order; a term whose variants exceed what remains matches as typed. A repeated term is matched once, in owner search too. ([#35](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/35))
- **`faa_search_registrations` filters** — `engineManufacturerModelCode`, `airworthinessClass`, and `yearManufacturedMin`/`yearManufacturedMax`, with error reasons `invalid_engine_code`, `invalid_airworthiness_class` and `invalid_year_range`. Summaries carry `engineManufacturerModelCode` and `airworthinessClass`. ([#36](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/36))

## Changed

- **`faa_search_aircraft_types`** lists named manufacturers before withheld ones under redaction. ([#37](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/37))

## Fixed

- **`faa_get_registration_status`** labels a reserved record's `expirationNoticeDate` as `**Reservation expiration:**` and describes it as the reservation expiration date (FAA `EXP DATE`), not the date a notice was sent. ([#33](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/33))
- **Make/model and owner search** ignore terms with no letter or digit. Before, `cessna - 172` matched no rows and an owner term such as `&` emptied the search.
- **Server instructions and `FAA_REDACT_OWNER_PII` descriptions** in `server.json` and `manifest.json` say builder names matching a current or former registrant are withheld, not every personal builder name.
- **`docs/design.md`** corrects the ENGINE row count and the indexed-lookup list.
- **README** notes that after a rollback in which an older version refreshed the index, `mirror:refresh` runs again with the current version.

## Security

- **Builder redaction** withholds a non-type-certificated builder name that matches a current or former registrant of an aircraft with that model code, comparing names as word sets part by part. A current corporate, government or LLC registrant with the same words keeps the name public. Store schema v3 resets the stored classification. ([#32](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/32))
