# 0.2.0 — 2026-11-10

Stop older writers before upgrading a shared mirror. Run `mirror:refresh` after upgrading to populate manufacturer classification, cancellation details, and the archive date.

## Added

- Published FAA registry guide for model discovery and N-number reassignment, available through the MCP Skills extension.
- **Cancellation history** includes all known cancellations for active, reserved, and deregistered N-numbers, newest first. Deregistered results include available make, model, export country, and manufacture year. ([#26](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/26))
- **Serial search** adds an exact, case-insensitive `serialNumber` filter to `faa_search_registrations` and includes stored serials in matching results. ([#27](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/27))
- **Registration details** include class-specific approved operations alongside the raw codes and known per-engine horsepower and thrust, in lookup and the registration resource. ([#28](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/28))
- **`dataAsOf`** reports the FAA archive date on successful tool responses when known. Tools recommend refreshing when the date is missing or more than seven days old. ([#29](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/29))

## Changed

- **Search page sizes** above 200 clamp to 200 with a notice by default. Set `FAA_CLAMP_LIMITS=false` to reject oversized requests. ([#30](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/30))
- **Packaging checks and release tooling** follow the installed framework. Dependency installs use a one-day minimum release age.

## Fixed

- **Mirror CLI logging** emits progress and diagnostics for `mirror:init`, `mirror:refresh`, and `mirror:verify`. ([#21](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/21))
- **N-number status** resolves active, reserved, then deregistered. A current reservation takes precedence over an older cancellation. ([#23](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/23))
- **Mirror rebuilds** serve one complete snapshot per request. Queries return a retryable error during replacement or after an interrupted rebuild until a refresh succeeds. `mirror:verify` also rejects an incomplete snapshot. ([#24](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/24))
- **Make/model search** matches token prefixes in both search tools. Owner matching still uses whole tokens. ([#25](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/25))

## Security

- **Builder redaction** withholds personal builder names and matching kit-manufacturer aliases from results, matching, counts, and ordering. Redacted queries conservatively withhold unclassified non-type-certificated manufacturers until the mirror refreshes. ([#22](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/22))
