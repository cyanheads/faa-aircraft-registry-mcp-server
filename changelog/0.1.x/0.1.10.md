# 0.1.10 — 2026-10-08

## Changed

- **Tool and resource error envelopes carry `data.requestId`**, and a tool error's text closes with `request <id>` — `cyanheads/mcp-ts-core#576` (0.13.10). The id is always framework-generated; the client's JSON-RPC id is logged as `jsonRpcId` — `cyanheads/mcp-ts-core#584` (0.13.12).
- **Error `data` no longer carries server stack traces** (`cyanheads/mcp-ts-core#519`, 0.13.7), **request context** (`cyanheads/mcp-ts-core#548`, 0.13.8), or `rootCause` (`cyanheads/mcp-ts-core#644`, 0.13.13).
- **Arguments are repaired before validation**: an integer sent for a string field such as `nNumber: 12345` (`cyanheads/mcp-ts-core#487`, 0.13.9); a numeric string for `limit`/`offset`, and `null` at an optional key, treated as absent (`cyanheads/mcp-ts-core#707`, `cyanheads/mcp-ts-core#616`, 0.13.14). `-32602` argument rejections name field paths in their hints (`cyanheads/mcp-ts-core#493`, 0.13.9) and are size-bounded (`cyanheads/mcp-ts-core#648`, 0.13.14).
- **HTTP transport**: the MCP SDK moves to `^2.2.0` (installed 2.3.1); a 2026-07-28 POST without `MCP-Protocol-Version` is refused with `400`/`-32020` (0.13.9).
- **`ctx.log`'s mirror to the client honors `MCP_LOG_LEVEL` and masks sensitive fields** — `cyanheads/mcp-ts-core#621`, `cyanheads/mcp-ts-core#630` (0.13.11).
- **Mirror index**: opening the SQLite store sets `busy_timeout` before the first read and retries a busy WAL switch (`cyanheads/mcp-ts-core#607`, 0.13.11); a store that cannot open names the file, not its directory (`cyanheads/mcp-ts-core#635`, 0.13.12).
- **The eight `ctx.recoveryFor` forwards in tool, resource, and `registry-service` throws are removed**; the framework fills each declared recovery hint itself (`cyanheads/mcp-ts-core#579`, 0.13.10), so callers see the same hints as in 0.1.9.
- **Docker image installs production dependencies in a `$BUILDPLATFORM` `deps` stage** (no QEMU on the arm64 leg; `cyanheads/mcp-ts-core#575`, 0.13.10) and drops musl-only bindings (`cyanheads/mcp-ts-core#608`, 0.13.11). Bun 1.4.0 → 1.4.2 in the image and `packageManager`.
- **`server.json` npm entries launch via `npx`**, and the HTTP entry pins `MCP_TRANSPORT_TYPE=http` (`cyanheads/mcp-ts-core#622`, 0.13.11).
- **Ignore files**: `.gitignore` and `.dockerignore` match `.env*`, `.dockerignore` excludes `.mirror/` from the build context, and `.mcpbignore` excludes `docs/idea.md`, `logs/`, `.cache/`, `coverage/`, and `tests/`.
- **`.github/workflows/codeql.yml` runs one job per language** and uploads under `/language:<language>` (`cyanheads/mcp-ts-core#470`, 0.13.11).
- **`.env.example` and the README document telemetry and logging opt-ins**: `OTEL_EXPORTER_OTLP_ENDPOINT` alone exports traces and metrics, and nothing is exported to `localhost:4318` by default (`cyanheads/mcp-ts-core#523`, 0.13.7); `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` log export and `LOG_TOOL_FAILURE_PAYLOADS` (`cyanheads/mcp-ts-core#547`, `cyanheads/mcp-ts-core#291`, 0.13.8).
