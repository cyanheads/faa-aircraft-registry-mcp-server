# 0.1.12 — 2026-10-17

## Changed

- **Setup documentation** uses compiled mirror commands for installed packages and Desktop bundles; source checkouts build before initializing the mirror.
- **Artifact regression tests** run separately with `bun run test:package`, covering npm and cleaned MCPB lifecycle commands, Node/Bun queries, and native prebuild retention.

## Fixed

- **Mirror CLI** ships as compiled `dist/cli/*.js` with package-relative imports in npm, MCPB, and Docker artifacts. Run init, refresh, and verify without source files or checkout configuration. ([#17](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/17))
- **Node SQLite runtime** includes the existing `better-sqlite3 ^13.0.3` as a production dependency, retaining all eight bundled N-API prebuilts for macOS, Windows, and Linux glibc/musl on x64/arm64 through MCPB cleaning. ([#18](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/18))
