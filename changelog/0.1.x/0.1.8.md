# 0.1.8 — 2026-08-24

## Added

- **MCP 2026-07-28 support** alongside initialize-negotiated 2025 clients.
- **Registration resource cache guidance** marking each response private and cacheable for one hour.

## Changed

- **Tool contracts reject undeclared root inputs** and advertise SDK-valid structured error envelopes.
- **Domain validation failures** now use `ValidationError` for malformed N-numbers and codes, missing search filters, and disabled search fields; `InvalidParams` remains reserved for malformed request shape.
- **Session mode is explicitly stateless** across `.env.example`, the Docker image, and the README.
- **Tool, resource, mirror lifecycle, and packaging descriptions** are shorter and match the implemented behavior.
- **Build and release maintenance** adopts Bun 1.4, TypeScript 7, test typechecking, tool-contract integration coverage, leaner Docker installs, current packaging scripts and skills, and community health files.
- **Security reporting guidance** uses `security@caseyjhand.com` and asks reporters to redact credentials.
