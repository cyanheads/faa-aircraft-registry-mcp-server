# 0.1.6 — 2026-07-16

## Fixed

- **FAA zero-sentinel fields** — `cruise_speed`, `year_mfr`, and `num_seats` values of literal `0` (the FAA's blank/unknown convention for these permissible fields) now render as absent instead of a fabricated `0 mph` cruise or a `year 0` aircraft; `num_engines = 0` is left untouched since it's a real value on unpowered aircraft (gliders, balloons) ([#1](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/1)).
- **Malformed identifiers** — `faa_lookup_registration`, `faa_get_registration_status`, `faa_get_aircraft_type`, and the `faa://registration/{nNumber}` resource now reject structurally invalid N-numbers and manufacturer/model/series codes with an `InvalidParams` error and a recovery hint, instead of a misleading `not_found`/`unknown` answer. Shape patterns were validated against the full registry corpus (313,930 active N-numbers, 93,817 aircraft reference codes) with zero false rejections ([#5](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/5)).
