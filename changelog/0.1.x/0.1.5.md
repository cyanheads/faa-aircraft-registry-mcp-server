# 0.1.5 — 2026-07-16

## Changed

- **Dockerfile** — `org.opencontainers.image.description` OCI label synced to `package.json`'s current description (previously carried older wording).

## Fixed

- **Registry rebuild** — full mirror rebuild (`mirror:init`/`mirror:refresh`) peak memory now scales with the **largest single file** in the FAA archive instead of the sum of all files, via lazy per-entry ZIP inflation (`zip.ts`'s `openZipArchive`/`readEntry`, replacing eager `readZipEntries`), streamed latin1 line decoding (`csv.ts`'s `parseCsv` now takes the raw entry `Buffer`), and `PAGE_SIZE`-chunked auxiliary-table transactions. Measured peak RSS on a real `mirror:refresh` dropped from ~2.35 GiB to ~0.74 GiB, with identical row counts ([#6](https://github.com/cyanheads/faa-aircraft-registry-mcp-server/issues/6)).
