# 0.1.9 — 2026-09-20

## Added

- **`createApp({ sessionMode: 'stateless', teardown })`** — the session posture is now declared in source rather than left to `MCP_SESSION_MODE` alone, and a new `teardown` hook (`src/lifecycle.ts`) removes the daily refresh cron and closes the mirror handle, in that order, on every shutdown path.

## Changed

- **Bun engines floor raised to `>=1.4.0`**, required by an upstream mirror-driver fix.
- **Argument rejections carry a recovery hint and `data.reason: "invalid_arguments"`** on the wire; a thrown contract error's `content[]` text now closes with `(reason <reason> · not retryable)` when `data.reason` or `data.retryable` is set. Assertions pinning that text exactly should switch to containment.
- **`FAA_REDACT_OWNER_PII`, `FAA_MIRROR_PATH`, and `FAA_DATABASE_URL` treat an empty string or an unsubstituted `${...}` placeholder as unset**, falling through to their default/redacted behavior instead of being parsed as literal text.
- **SIGTERM/SIGINT exit the process explicitly** — `0` once shutdown settles, `1` if a 10s ceiling fires — rather than waiting for the event loop to drain.
- **Development skills moved from `skills/` to `framework-skills/`** — Claude Code and Codex auto-load a plugin's root `skills/`, so this server (which ships `.claude-plugin/`/`.codex-plugin/`) no longer hands its development skills to every installing agent. Repo-hygiene and doc sync: issue templates, CONTRIBUTING links, the plugin manifest schema/keywords, and a README reorganized into one capability-reference section per tool and resource.
